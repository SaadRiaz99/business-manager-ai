01 — LOCAL INSTALLATION

Run BizPilot AI on Windows

Use PowerShell from the project directory.

1
Download the latest code
git clone https://github.com/SaadRiaz99/business-manager-ai.git cd business-manager-ai
2
Create and activate a virtual environment
python -m venv .venv .venv\Scripts\Activate.ps1
3
Install dependencies
python -m pip install --upgrade pip pip install -r requirements.txt
4
Start the FastAPI server
python -m uvicorn app.main:app --reload
Open the application: http://127.0.0.1:8000
Open API documentation: http://127.0.0.1:8000/docs

Run automated tests

python -m pytest -q python -m compileall -q app tests

02 — MULTI-AGENT WORKFLOW

How the automation planner works

The orchestrator reads the business type and goal, then selects the specialists needed to create a coordinated plan.

Sales Agent

Lead capture, qualification, opportunities, and follow-ups.

Marketing Agent

Offers, campaigns, content, and channel measurement.

Operations Agent

Processes, checklists, owners, deadlines, and exceptions.

Finance Agent

Revenue, costs, invoices, margins, and cash flow.

Customer Support Agent

Request routing, draft replies, service, and escalation.

Human Approval

Required for external messages, payments, refunds, and destructive actions.

Example request

POST /api/automation/plan { "business_name": "Saad Demo School", "business_type": "Local School", "goal": "Automate admissions, parent messages, fees, and reporting", "channels": ["WhatsApp", "Email"] }

Useful API endpoints

EndpointPurpose
POST /api/automation/planCreate and save a coordinated plan
GET /api/automation/runsView the last 20 plans
GET /api/leadsView prioritized leads
GET /api/metricsView business KPIs

03 — VERCEL DEPLOYMENT

Publish the application

  1. Import the GitHub repository into Vercel.
  2. Keep the project root at the repository root.
  3. No build command is required; vercel.json points to api/index.py.
  4. Deploy the main branch.
  5. Set DATABASE_URL to managed PostgreSQL before real production use.
Current production blocker: Vercel Authentication is enabled. Public visitors are redirected to Vercel sign-in and API requests return 401. In Vercel, open Project → Settings → Deployment Protection, disable protection for Production, and redeploy before sharing the marketing link.

Production test checklist

  • Homepage returns HTTP 200 without sign-in
  • Dashboard works on desktop and mobile
  • Metrics, leads, and tasks load
  • Automation form returns specialist cards
  • Automation history saves correctly
  • Invalid requests return clear validation errors
  • No browser console errors
  • Persistent production database is configured
  • Sensitive actions require human approval
